# わらうた

芸人のお笑いライブ、アーティストのツアー・フェス、チケットの先行・抽選・一般発売の情報を
毎日自動で集めて表示する非公式まとめサイトです（飯飯食堂と同じしくみ）。

## しくみ

- `scripts/fetch_live.py` … Bingニュース / Googleニュースのキーワード検索RSSと PR TIMES の新着RSSから見出しを集め、
  ジャンル（お笑い / アーティスト）・種類（申込・チケット / 開催決定 / フェス・出演 / 中止・延期 / レポート）・エリアを自動で振り分けて
  `data/live.json` に保存します（標準ライブラリのみ）。
- 見出しに「11/10まで」「12/1から一般発売」のような日付があれば、申込締切・受付開始日として読み取り、
  トップの「これからの申込」に近い順で並べます。締切や公演日がまだ先の情報は、古くなっても消さずに残します。
- `.github/workflows/update.yml` … 毎日3回（6:13・12:13・18:13 日本時間）上のスクリプトを実行し、GitHub Pages に公開します。
- `index.html` / `assets/` … `data/live.json` を読み込んで表示するページです。

## 初回設定

1. このフォルダの中身をすべて、作ったリポジトリのいちばん上にアップロード（コミット）する
   （`.github` フォルダと `.nojekyll` も忘れずに）
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブ → 「ライブ情報の更新と公開」 → **Run workflow** で1回手動実行する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示されます

## 推し（追いかける芸人・アーティスト）を変える

- `oshi.json` の `geinin`（芸人）と `artist`（アーティスト）に名前を書くと、毎日その名前でも検索します。
  見出しに名前が入っていれば、そのジャンルとして扱います。
- サイトの「推しリスト」からも名前を追加できます（その端末にだけ保存。検索には使われません）。

## 集める情報を調整する

- `scripts/fetch_live.py` の `QUERIES` … 検索キーワードの一覧。足したり消したりできます。
- `NOT_WANTED_WORDS` … 載せたくない記事に出てくる言葉（例：野球、歌舞伎）。
- `TYPES` / `AREAS` … 種類とエリアを見分ける言葉。
- 更新の回数を増やすときは `update.yml` の `cron` を書き換えます（時刻はUTCなので日本時間から9時間引きます。例：4回なら `"13 21,3,9,13 * * *"`）。

## 注意

- 見出しから自動で読み取っているため、日付や種類がずれることがあります。日時・申込方法は必ず出典元・公式サイトで確認してください。
- 記事本文は保存せず、見出し・出典・リンク・写真のURLだけを載せています。
